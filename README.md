# City-Motors — Plateforme B2B de vente de roulements

Le projet reprend la direction artistique « Orbital Précision » fournie et cible l’approvisionnement professionnel en roulements industriels.

## Design fourni
Le fichier de référence HTML est disponible dans [docs/orbital-precision-index.html](./docs/orbital-precision-index.html). Il définit le document HTML, les métadonnées, les polices et la palette sombre bleu nuit avec accents orange/cyan.

> Note : le fichier fourni référence une application Vite/React via `/src/main.tsx`. Le ZIP reçu ne contenait pas le dossier `src/` ni les composants de l’application. Le dépôt contient donc le point d’entrée/design HTML, mais pas encore l’interface React complète exécutable.

Voir [docs/PLAN-DE-DEVELOPPEMENT.md](./docs/PLAN-DE-DEVELOPPEMENT.md) pour le planning révisé sur six semaines, le backlog et les critères de validation.
